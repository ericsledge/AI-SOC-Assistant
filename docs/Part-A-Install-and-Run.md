- ☁️ GitHub

# 💻 System Requirements

Before installing the project, make sure your computer meets the following minimum requirements.

| Component | Minimum Requirement | Recommended |
|-----------|---------------------|-------------|
| Operating System | Windows 10 | Windows 11 |
| Processor | Dual-Core CPU | Quad-Core or better |
| Memory (RAM) | 8 GB | 16 GB or more |
| Storage | 10 GB free | 20 GB or more |
| Internet | Required for installation | Broadband |

> ℹ️ The project uses a local Large Language Model (LLM). More RAM generally results in better performance.
